# 3.7.8 应收账款管理 - UI/UX 补充说明

本说明旨在指导“应收账款管理”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“确认 -> 收款核销 -> 坏账计提”的闭环。

## 1. 模块 UI 目标
- **账龄分布可视化**：通过直观的视觉反馈展示各阶段账龄金额。
- **坏账逻辑专业化**：专业展示计提、补计提、确认、收回等复杂账务操作。
- **核销状态透明化**：清晰展示每一笔应收的收款进度及剩余风险。

## 2. 页面清单
- **表单类**：应收账款确认单、收款/核销单、通用坏账计提单、单项坏账申请单。
- **台账类**：应收账款台账、坏账处理台账。

## 3. 页面布局重点
- **应收台账页**：顶部展示账龄分布统计图（Mock，如 Stacked Bar Chart），展示 1年内、1-2年...的金额分布。
- **坏账计提单**：采用多列宽表格，每一行包含 5 个账龄区间的输入与计算。
- **单项坏账单**：根据“处理类型”切换不同的金额展示重心。

## 4. 列表页字段与表格列建议
### 4.1 应收账款台账
- **主要表格列**：客户名称、应收总额、应收余额、账龄区间、风险等级、收款状态。
- **视觉标签**：高风险客户（账龄长、金额大）使用红色风险图标标记。

## 5. 新增 / 编辑 / 详情展示方式
- **自动计提计算**：在通用计提单中，输入计提比例后，行内的“本期计提金额”秒级更新。
- **核销余额对照**：收款单中，实时显示 `原金额 - 本次收款 = 剩余金额` 的动态反馈。
- **账龄明细展示**：详情抽屉中使用进度条或分段色彩展示账龄结构。

## 6. 核心操作按钮与反馈
- **模拟收款核销**：行内按钮，点击后打开收款单并预填客户信息。
- **生成计提凭证**：计提单通过后的动作，弹出凭证预览图。
- **重试同步**：当模拟同步金蝶失败时，在台账状态旁提供一键重试。

## 7. 状态标签与状态流转展示
- **未收款 / 未计提**：`bg-slate-100 text-slate-600`
- **部分收款 / 计提中 / 核销中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已收清 / 已计提 / 已核销**：`bg-green-50 text-green-600 border-green-200`
- **逾期风险 / 计提失败**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **金蝶凭证关联**：详情页显眼位置展示 `金蝶凭证: VOU-202605-XXX`。
- **银行流水匹配**：收款单中增加“模拟匹配银行流水”按钮，点击后自动勾选匹配的记录。

## 9. normal / loading / empty / error 状态补充
- **Loading**：大型应收台账翻页时使用列表骨架屏。
- **Error**：补计提金额出现异常负值且无说明时，在提交按钮旁展示错误提示。

## 10. Codex 实现注意事项
- **账龄计算器**：编写一个简单的逻辑，根据“到期日”自动计算逾期天数并归类至账龄区间。
- **计提汇总逻辑**：实现多行账龄计提金额在单据底部的实时汇总计算。
