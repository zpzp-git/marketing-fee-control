# 3.7.17 销售合同 - UI/UX 补充说明

本说明旨在指导“销售合同”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“结构化规则 -> 销售结算 -> 返利计提”的渠道管理闭环。

## 1. 模块 UI 目标
- **规则配置结构化**：清晰展示不同电商渠道（得物、京东等）的多样化结算与返利规则。
- **结算计算自动化**：直观展示从销售额到服务费金额的计算过程。
- **阶梯计提引导化**：通过可视化进度条，辅助用户确定销售返利的阶梯命中情况。

## 2. 页面清单
- **台账类**：销售合同台账（合同库）、结算/返利台账。
- **表单类**：销售合同结构化维护、销售合同结算单、销售返利计提单。

## 3. 页面布局重点
- **销售合同结构化**：采用纵向分步式卡片布局：`基础信息` -> `结算规则` -> `返利阶梯` -> `履约概览`。
- **结算/计提单**：左侧展示合同核心规则摘要，右侧展示本期数据录入。
- **返利计提页**：展示返利阶梯示意图，标记当前累计销售额所处的区间。

## 4. 列表页字段与表格列建议
### 4.1 销售合同台账
- **主要表格列**：合同编码、客户、销售渠道、服务费率、合同状态、累计销售额、操作。
- **图标标识**：不同渠道使用品牌色彩标识（如：`得物`-黑色，`京东`-红色）。

## 5. 新增 / 编辑 / 详情展示方式
- **结算录入**：在结算单中，输入“本期销售额”后，系统自动执行 `销售额 * 费率` 并弹出计算动画。
- **阶梯命中**：返利计提单中，自动根据累计销售额选中对应的阶梯行，并填充返利比例。
- **履约摘要**：详情页顶部展示：`已结算服务费`、`累计已计提返利`、`剩余销售限额`等摘要值。

## 6. 核心操作按钮与反馈
- **模拟同步账单**：结算单右上角动作，点击后自动从电商 mock 接口获取本月销售数据。
- **审批回写合同**：计提单通过后，合同全景页的“累计返利”数字执行一个上升的数值滚动效果。
- **发起返利调整**：允许手动修改计提金额，修改后背景变黄并强制填写“调整说明”。

## 7. 状态标签与状态流转展示
- **草稿 / 未同步**：`bg-slate-100 text-slate-600`
- **已生效 / 结算中 / 计提中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已完成 / 已结算**：`bg-green-50 text-green-600 border-green-200`
- **已驳回 / 同步失败**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **电商平台标识**：结算明细旁展示 `[京东]`、`[得物]` 等图标。
- **同步进度条**：点击“同步账单”后显示一个虚假但逼真的进度条：`正在连接 API` -> `正在下载账单` -> `解析完成`。
- **外部单据预览**：点击“来源单据”可查看电商账单原始样式的 Mock 抽屉。

## 9. normal / loading / empty / error 状态补充
- **Empty**：无生效合同无法新建结算单，展示“当前无生效合同，请先完成合同结构化”。
- **Error**：计提返利大于可返利总额时，提交按钮旁展示红色警示文本。

## 10. Codex 实现注意事项
- **阶梯匹配 JS**：编写一个 `matchRebateTier(amount, tiers)` 函数，模拟阶梯命中逻辑。
- **金额自动更新**：实现表单内销售额变动时，服务费与结算总额的毫秒级实时计算。
- **字段只读逻辑**：确保已复核过的合同关键结算字段在结算单中为只读。
