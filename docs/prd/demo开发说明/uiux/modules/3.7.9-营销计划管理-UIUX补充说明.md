# 3.7.9 营销计划管理 - UI/UX 补充说明

本说明旨在指导“营销计划管理”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“计划 -> 活动 -> 预算占用 -> 执行回写”的闭环。

## 1. 模块 UI 目标
- **执行进度直观化**：通过计划详情页展示各活动的执行比例与预算剩余情况。
- **多级关联清晰化**：清晰展示计划、活动、合同、PO、费用预估五者之间的父子及横向关系。
- **数据回写实时化**：演示执行端数据（PO、结算）如何自动反哺至计划台账。

## 2. 页面清单
- **表单类**：新增/编辑营销计划（含多活动维护）。
- **台账类**：营销计划台账。
- **详情类**：营销计划详情（全景监控页）。

## 3. 页面布局重点
- **计划台账页**：顶部摘要：`计划总数`、`占用预算总额`、`实际执行金额`、`进行中数`。
- **计划表单页**：采用“基本信息+活动明细列表”布局。活动明细支持行内折叠展示“执行明细”。
- **详情监控页**：使用 Tab 分组：`概览` | `活动明细` | `PO记录` | `结算/预估记录` | `审批记录`。

## 4. 列表页字段与表格列建议
### 4.1 营销计划台账
- **主要表格列**：计划编号、计划名称、状态、开始日期、占用预算、实际支出、预算执行率、操作。
- **执行率展示**：使用线性进度条展示预算执行率（实际支出/占用预算）。

## 5. 新增 / 编辑 / 详情展示方式
- **批量活动维护**：支持从 Excel 样式表格批量粘贴或快速新增活动行。
- **合同/预算关联**：在活动行内提供搜索弹窗，选择合同后展示该合同的“可用余额”。
- **单次执行模式**：切换计划类型时，表单自动简化为单行模式，聚焦核心字段。

## 6. 核心操作按钮与反馈
- **模拟执行回写**：详情页工具栏按钮，点击后播放数据同步动画，随后表格中的“实际结算”数字更新。
- **复制计划**：台账行内操作，点击后直接跳转至预填好基础信息的“新增计划”页。
- **终止计划**：需弹出确认框，告知将释放的预算占用额。

## 7. 状态标签与状态流转展示
- **未开始 / 待生效**：`bg-slate-100 text-slate-600`
- **进行中 / 审批中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已完成 / 已结案**：`bg-green-50 text-green-600 border-green-200`
- **已终止 / 已过期**：`bg-gray-200 text-gray-500`

## 8. 第三方系统 mock 展示方式
- **达人系统链接**：任务 ID 展示为蓝色链接，点击提示“已模拟跳转至达人平台查看任务详情”。
- **预算系统占用**：单据生效后，展示一个“预算已预扣”的绿色成功徽章。
- **活动状态自动机**：随着 PO 回写，活动状态自动从“未开始”转为“进行中”。

## 9. normal / loading / empty / error 状态补充
- **Loading**：数据回写过程中，显示全屏局部半透明遮罩及加载文本“正在同步执行数据...”。
- **Empty**：查询无计划时展示“本月暂无营销计划，点击创建开始”。

## 10. Codex 实现注意事项
- **执行汇总计算**：实现明细行回写数据自动汇总至计划顶部的逻辑。
- **状态推导逻辑**：根据活动的起止日期与当前日期，以及是否有执行数据，自动推导计划状态。
- **预算强校验**：实现提交时比对“预估预算”与“可用余额”的 mock 校验。
