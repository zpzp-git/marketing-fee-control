# 3.7.11 发票管理 - UI/UX 补充说明

本说明旨在指导“发票管理”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“待到票 -> 核销/无票申请 -> 台账更新”的演示闭环。

## 1. 模块 UI 目标
- **到票进度可视化**：直观展示每个结算事项的到票金额与待到票余额。
- **查验反馈实时化**：模拟发票上传后的自动查验反馈。
- **核销链路清晰化**：清晰展示结算单、发票、预付款三者之间的对冲关系。

## 2. 页面清单
- **台账类**：待到票台账、发票核销台账、无票核销申请台账。
- **表单类**：发票核销单、发票红冲单、无票核销申请单。

## 3. 页面布局重点
- **待到票台账**：采用“工作池”风格。顶部摘要：`待到票总额`、`到票中金额`、`未到票金额`、`查验失败数`。
- **发票核销单**：采用多区块卡片布局：`结算明细`、`预付核销`、`发票信息`（核心区块）。
- **核销详情抽屉**：侧边展示发票预览图（Mock）与核销后的凭证分录。

## 4. 列表页字段与表格列建议
### 4.1 待到票台账
- **主要表格列**：结算单号、供应商、营销活动、待到票总额、已到票金额、未到票金额、发票状态。
- **颜色提示**：未到票金额 > 0 时，金额可使用深灰色；已完结使用绿色。

### 4.2 发票核销台账
- **主要表格列**：核销单号、核销日期、供应商、已核销金额、凭证号、红冲状态、操作。

## 5. 新增 / 编辑 / 详情展示方式
- **发票录入**：提供“模拟上传”按钮，点击后自动填充发票号码、代码、金额等字段，并展示“查验通过”绿标。
- **预付对冲**：如果供应商有预付余额，自动弹出“预付核销”提示框，建议用户勾选。
- **红冲逻辑**：从核销台账发起红冲，表单以红色警示色调为主，突出“冲回”动作。

## 6. 核心操作按钮与反馈
- **查验发票**：行内按钮，点击后显示 Loading 状态（1s），反馈查验结果。
- **提交核销**：点击后进入“财务签收”环节，台账中的“到票中金额”即时增加。
- **生成凭证**：审批完成后，右上角出现“生成凭证”按钮，点击后显示凭证预览并模拟同步。

## 7. 状态标签与状态流转展示
- **发票未到**：`bg-slate-100 text-slate-600`
- **部分到票 / 到票中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已到票完结 / 已无票核销**：`bg-green-50 text-green-600 border-green-200`
- **查验失败 / 已红冲**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **发票查验模拟**：上传发票后，显示“金税三期自动查验中...”，随后展示结果。
- **凭证号回写**：财务审批后，页面显眼位置展示 `凭证号: KD-2026-XXXX`，带一键复制。
- **同步金蝶**：同步成功后，详情页底部展示“已于 2026-05-06 10:00 同步至金蝶总账”。

## 9. normal / loading / empty / error 状态补充
- **Empty**：待到票台账为空时，展示“所有结算单均已到票，当前无待处理事项”。
- **Error**：上传发票金额大于结算余额时，表单底部展示红色 Alert：“核销金额超限”。

## 10. Codex 实现注意事项
- **多选逻辑**：实现待到票记录的多选核销，并自动汇总金额。
- **发票池 Mock**：建立一个本地 json 发票池，支持根据号码快速搜索带出数据。
- **凭证预览**：实现一个简单的会计分录预览 UI，展示借贷方科目（Mock）。
