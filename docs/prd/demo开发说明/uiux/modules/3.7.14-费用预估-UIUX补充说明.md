# 3.7.14 费用预估 - UI/UX 补充说明

本说明旨在指导“费用预估”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“数据生成 -> 预估台账 -> 预提/对账”的转换与闭环。

## 1. 模块 UI 目标
- **转换逻辑透明化**：展示原始账单如何经过规则映射变为预估台账的过程。
- **多维台账集成化**：为不同类型的费用（摊销、投放、直播）提供统一且专业的查阅界面。
- **财务状态可视化**：清晰展示每一笔预估费用的预提状态与对账状态。

## 2. 页面清单
- **工作台**：费用预估工作台（汇总视图）。
- **台账类**：合同摊销费用台账、单次执行费用预估台账、投放费用预估台账、直播费用预估台账、平台扣款费用台账、代运营业务数据台账。

## 3. 页面布局重点
- **预估台账群**：采用“强筛选+大表格”模式。表格支持列定制，以应对多维度的业务字段。
- **转换记录抽屉**：展示预估费用的“前世今生”，左侧显示原始账单行，右侧显示生成的台账行。
- **合同摊销视图**：展示摊销进度条（Progress Bar），直观体现“已摊销”与“待摊销”比例。

## 4. 列表页字段与表格列建议
### 4.1 投放费用预估台账
- **主要表格列**：费用日期、投放账号、供应商、现金消耗、折扣率、预估费用、是否预提、是否对账、操作。

### 4.2 合同摊销费用台账
- **主要表格列**：合同编号、合同标题、摊销总额、已摊销金额、日摊销金额、状态、操作。

## 5. 新增 / 编辑 / 详情展示方式
- **批量预提**：支持在台账中勾选多条记录，顶部出现“合并生成预提单”浮动栏。
- **规则命中提示**：在平台扣款详情中，高亮显示命中的“费用小类映射规则”。
- **中止摊销弹窗**：点击中止时，展示剩余摊销金额的结算建议。

## 6. 核心操作按钮与反馈
- **模拟同步账单**：工作台主按钮，点击后展示多步骤进度条（同步 -> 转换 -> 生成）。
- **发起对账**：行内操作，点击后弹出对账编辑框，支持录入差异原因。
- **重新转换**：针对失败记录的修复操作，点击后刷新当前行状态。

## 7. 状态标签与状态流转展示
- **未生成 / 未对账**：`bg-slate-100 text-slate-600`
- **摊销中 / 预提中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已对账 / 已摊销完毕**：`bg-green-50 text-green-600 border-green-200`
- **有差异 / 生成失败**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **RPA 运行状态**：展示“影刀机器人正在解析账单文件...”，增加演示趣味性。
- **OMS 数据源标记**：平台扣款记录旁展示 `[OMS]` 标识。
- **对账单关联**：对账完成后，展示一个可点击的“结算单号”链接，模拟跳转结算页。

## 9. normal / loading / empty / error 状态补充
- **Empty**：台账无数据时，展示“本月尚未同步业务账单，点击顶部按钮开始”。
- **Loading**：转换过程中，表格行呈现半透明状并伴随 Shimmer 动画。

## 10. Codex 实现注意事项
- **计算引擎 Mock**：实现简单的摊销计算公式：`(总额 / 天数) * 经过天数`。
- **规则匹配模拟**：编写一个简单的 key-value 映射表，模拟平台扣款的规则引擎逻辑。
- **状态同步**：确保预提操作后，对应的“预提金额”和“单号”字段在表格中实时可见。
