# 3.7.2 预算管理 - UI/UX 补充说明

本说明旨在指导“预算管理”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“年度编制 -> 滚动预测 -> 预算调整”的财务管控闭环。

## 1. 模块 UI 目标
- **数据矩阵专业化**：针对年度及月度预算的大量数值输入，提供高效的电子表格交互体验。
- **管控预警直观化**：在编制和预测过程中，通过醒目的 UI 标识展示超额风险。
- **多维汇总可视化**：提供清晰的维度切换（渠道、品类、部门），支持数据的层层钻取。

## 2. 页面清单
- **表单类**：年度预算编制单、月度预测编制单、预算调整单。
- **台账类**：年度预算查询台账、汇总年度预算台账、月度预测结果台账、收入预算台账（渠道/品类）、预算管控策略。

## 3. 页面布局重点
- **预算编制页**：核心是一个包含 `1月-12月` 的宽表格，左侧固定科目维度，右侧合计列自动重算。
- **汇总台账页**：采用“树形折叠”结构，允许从事业部汇总值展开至末级部门明细。
- **管控策略页**：以卡片形式展示不同的控制规则，包含阈值、周期和开关状态。

## 4. 列表页字段与表格列建议
### 4.1 年度预算查询台账
- **主要表格列**：预算科目、部门、全年合计、1-12月分布、已占用、可用余额、状态。
- **金额对齐**：所有数值列强制右对齐，使用等宽字体。

## 5. 新增 / 编辑 / 详情展示方式
- **宽表交互**：支持 Tab 键快速切换单元格，输入金额后整行合计及页面总计实时刷新。
- **超额提示**：在月度预测中，当 `预测总额 > 年度预算` 时，该单元格背景色变为浅橙色，并显示提示图标。
- **调整明细**：在预算调整单中，采用“增/减”分栏对比，清晰展示调整前后的差额。

## 6. 核心操作按钮与反馈
- **模拟汇总**：财务复核时的专属操作，点击后触发全屏 Loading（1s），提示“已完成 152 个部门的预算汇总”。
- **校验余额**：编制单中的实时动作，点击后在行内展示“预算充足”或“余额不足”提示。
- **导出模板**：提供标准的 Excel 样式模板下载（弹出下载成功 Toast）。

## 7. 状态标签与状态流转展示
- **草稿 / 未提交**：`bg-slate-100 text-slate-600`
- **审批中 / 汇总中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已生效 / 汇总完成**：`bg-green-50 text-green-600 border-green-200`
- **超预算 / 已驳回**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **OA 流程预览**：在详情页展示标准的 OA 审批节点：`申请 -> 部门负责人 -> 财务 BP -> 财务总监`。
- **同步经分看板**：点击“同步经分”后，展示“数据已推送至经营分析系统”的反馈。

## 9. normal / loading / empty / error 状态补充
- **Loading**：大型预算表加载时使用 Skeleton 骨架屏。
- **Error**：如果 1-12 月份合计与全年总额不符，在总计单元格旁展示红色警告。

## 10. Codex 实现注意事项
- **宽表组件**：封装一个支持横向滚动的 Table 组件，并固定左侧 3-4 列。
- **实时计算逻辑**：编写 JS 函数，处理行、列及页面的三维金额汇总。
- **单元格状态**：为预算单元格实现三种视觉状态：`默认`、`修改中`、`校验异常`。
