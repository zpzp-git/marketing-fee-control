# 3.7.3 营销备用金 - UI/UX 补充说明

本说明旨在指导“营销备用金”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“借款 -> 报销冲销 -> 状态完结”的闭环。

## 1. 模块 UI 目标
- **借贷平衡透明化**：清晰展示每一笔备用金的借款金额与后续冲销进度的对比。
- **关联引用便捷化**：在申请和报销时，能够快速关联营销事项。
- **付款状态实时化**：模拟 CBS 支付过程，展示从审批到最终打款的视觉反馈。

## 2. 页面清单
- **表单类**：营销备用金申请单、营销备用金报销单。
- **台账类**：专项备用金台账。

## 3. 页面布局重点
- **报销单页面**：采用“左右/上下”对比，左侧录入费用明细，右侧或下方专门展示“备用金冲销”区块。
- **借款申请页**：突出“收款信息”区块，包含开户行、账号等核心字段。
- **备用金台账**：采用“进度条/仪表盘”风格，直观展示每个员工/事项的“已还/未还”比例。

## 4. 列表页字段与表格列建议
### 4.1 专项备用金台账
- **主要表格列**：借款人、申请日期、借款总额、已还款金额、未还款金额、还款进度、完结状态。
- **视觉提示**：未还款金额大于 0 时，使用醒目的深灰色；已完结使用绿色勾选图标。

## 5. 新增 / 编辑 / 详情展示方式
- **事项关联**：在申请单中，提供一个“选择营销事项”的弹窗，展示事项名称、预算科目、可用额度。
- **冲销自动算**：在报销单中，输入“本次冲销金额”后，自动计算 `剩余应付金额 = 报销合计 - 冲销合计`。
- **凭证号查看**：详情页顶部展示该笔交易的业财凭证号。

## 6. 核心操作按钮与反馈
- **模拟付款**：财务审批后的“支付”操作，显示动画并反馈“支付指令已发送至银行”。
- **发起报销**：从台账行内直接点击，自动在报销单中带入该笔借款信息。
- **登记还款**：对于现金还款场景，弹出简单的金额和日期确认框。

## 7. 状态标签与状态流转展示
- **待付款 / 审批中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已支付 / 已完结**：`bg-green-50 text-green-600 border-green-200`
- **付款失败 / 已逾期**：`bg-red-50 text-red-600 border-red-200`
- **部分还款**：`bg-orange-50 text-orange-600 border-orange-200`

## 8. 第三方系统 mock 展示方式
- **CBS 流水展示**：详情页下方展示“CBS 支付日志”，包含支付时间、流水号、处理结果。
- **金蝶凭证同步**：展示 `[ERP]` 标识，点击可查看模拟的凭证分录。

## 9. normal / loading / empty / error 状态补充
- **Empty**：台账无数据展示“您当前没有未完结的备用金记录”。
- **Error**：报销金额小于冲销金额导致负数支付时，弹出拦截提示。

## 10. Codex 实现注意事项
- **联动重算**：确保费用行增减时，报销总额与实付金额的逻辑链条完整。
- **状态回写**：报销完成后，对应借款台账的“未还金额”必须立即扣减。
