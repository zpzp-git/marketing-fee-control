# 3.7.4 保证金管理 - UI/UX 补充说明

本说明旨在指导“保证金管理”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“付款申请 -> 台账记录 -> 财务退回”的资产管理闭环。

## 1. 模块 UI 目标
- **资产状态清晰化**：清晰区分在保、退回中、已退回三种资产状态。
- **分类属性直观化**：针对平台类（店铺/账户）与非平台类（合同/招标）提供差异化视图。
- **退回链路可视化**：展示从退回申请到财务确认到账的完整流程。

## 2. 页面清单
- **表单类**：保证金付款申请单、保证金退回申请单。
- **台账类**：保证金台账。

## 3. 页面布局重点
- **付款申请页**：根据“保证金类型”使用动态表单，平台类展示店铺/链接信息，非平台类展示合同/供应商。
- **保证金台账**：采用“资产卡片+数据表格”模式。顶部摘要：`保证金总额`、`待收回金额`、`已收回总计`。
- **退回申请页**：左侧展示台账原始信息（锁定），右侧输入本次退回详情。

## 4. 列表页字段与表格列建议
### 4.1 保证金台账
- **主要表格列**：单据编号、保证金类型、核算主体、对象(店铺/供应商)、保证金总额、余额、是否全额退回、状态。
- **金额对齐**：总额与余额强制右对齐。

## 5. 新增 / 编辑 / 详情展示方式
- **动态字段**：切换“保证金类型”下拉框时，下方表单区块使用平滑的过渡效果进行切换。
- **余额锁定**：退回申请单中，从台账关联带入的“保证金余额”显示为带有灰底的只读 Input。
- **历史记录**：台账详情中以时间轴形式展示“付款日期”与“各次退回日期”。

## 6. 核心操作按钮与反馈
- **确认到账**：财务专属操作，点击后弹出“核对到账流水”框，确认后更新余额。
- **重试付款**：支付失败时的行内按钮。
- **查看凭证**：链接至模拟的 ERP 收/付款凭证。

## 7. 状态标签与状态流转展示
- **付款中 / 退回中**：`bg-blue-50 text-blue-600 border-blue-200`
- **在保 (付款成功)**：`bg-green-50 text-green-600 border-green-200`
- **已全额退回**：`bg-gray-100 text-gray-600`
- **付款失败**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **支付网关模拟**：付款时展示一个仿真的支付网关处理弹窗：`招商银行直连支付中...`。
- **凭证号展示**：凭证生成后，在单据号旁展示 `ERP-VOUCHER-XXXX`。

## 9. normal / loading / empty / error 状态补充
- **Loading**：大型台账搜索时，表格中央展示 Spinner 且操作列置灰。
- **Error**：退回金额超过余额时，在 Input 下方实时展示红色校验提示。

## 10. Codex 实现注意事项
- **动态表单组件**：实现一个可根据 Type 字段动态渲染不同 Fields 的 Form 容器。
- **余额扣减逻辑**：实现从台账发起退回后，已退回金额累加及状态自动更新的逻辑。
