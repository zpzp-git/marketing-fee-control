# 3.7.12 内部领用 - UI/UX 补充说明

本说明旨在指导“内部领用”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“BPM 推送 -> 预算校验 -> 领用台账”的闭环。

## 1. 模块 UI 目标
- **入账流程自动化**：展示从外部 BPM 系统自动同步并生成业财单据的过程。
- **预算占用透明化**：在单据中直观展示预算校验结果及对预算台账的影响。
- **SKU 明细清晰化**：清晰展示领用的物品明细、单价及金额。

## 2. 页面清单
- **台账类**：内部领用台账。
- **表单类**：内部领用单。
- **辅助类**：BPM 推送记录（监控页）。

## 3. 页面布局重点
- **内部领用单**：采用“主表 + 明细表 + 预算汇总表”的三段式结构。
- **BPM 推送记录**：列表展示同步批次，右侧提供“模拟生成单据”操作。
- **预算校验区**：在表单明细下方展示汇总的预算检查结果，使用警示色标识预算不足。

## 4. 列表页字段与表格列建议
### 4.1 内部领用台账
- **主要表格列**：单据编号、核算主体、领用日期、申请人、业务用途、SKU名称、数量、单价、实付金额、预算科目、状态。
- **对齐规则**：数量、单价、金额强制右对齐。

## 5. 新增 / 编辑 / 详情展示方式
- **自动带出**：进入内部领用单后，自动填充来自 BPM 的只读字段。
- **预算映射**：提供“映射修正”操作，允许用户在预算科目匹配失败时手动选择。
- **明细详情**：点击 SKU 名称可弹出小抽屉展示产品图片及品牌信息（Mock）。

## 6. 核心操作按钮与反馈
- **模拟 BPM 推送**：监控页顶部按钮，点击后列表新增“待处理”记录。
- **执行预算校验**：表单工具栏按钮，点击后计算预算占用，反馈“通过”或“不足”。
- **审批通过**：点击后更新“预算实际发生额”，并弹出成功提示。

## 7. 状态标签与状态流转展示
- **待校验 / 待处理**：`bg-slate-100 text-slate-600`
- **审批中 / 校验通过**：`bg-blue-50 text-blue-600 border-blue-200`
- **已完成 / 已入账**：`bg-green-50 text-green-600 border-green-200`
- **预算不足 / 映射缺失**：`bg-orange-50 text-orange-600 border-orange-200`

## 8. 第三方系统 mock 展示方式
- **BPM 来源标识**：单据号旁展示 `[BPM]` 蓝色微型标签。
- **预算实时回写**：审批完成后，增加一个“预算台账已更新”的浮动提示。
- **推送失败展示**：在推送记录中点击“查看原因”，弹出详细的错误堆栈（Mock）。

## 9. normal / loading / empty / error 状态补充
- **Error**：当 SKU 映射失败时，该行背景色设为浅粉色，并在单元格内显示红色感叹号。
- **Empty**：推送记录为空时展示“当前无待同步的 BPM 领用数据”。

## 10. Codex 实现注意事项
- **映射逻辑**：编写简单的规则函数，根据“组织机构”自动返回“预算部门”。
- **金额汇总**：实现明细行变动时，主表总金额及预算区汇总的自动重算。
