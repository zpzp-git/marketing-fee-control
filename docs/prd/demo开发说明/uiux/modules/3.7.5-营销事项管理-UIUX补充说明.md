# 3.7.5 营销事项管理 - UI/UX 补充说明

本说明旨在指导“营销事项管理”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“事项申请 -> 预算占用 -> 费用核销 -> 关闭”的执行闭环。

## 1. 模块 UI 目标
- **事项进度透明化**：通过“已用/剩余”金额看板，直观展示每个营销事项的执行进度。
- **预算关联清晰化**：在申请阶段清晰展示所占用的预算科目及部门。
- **操作反馈即时化**：模拟各项业务（付款、报销）对事项金额的实时核销反馈。

## 2. 页面清单
- **表单类**：营销事项申请单、营销事项关闭单。
- **台账类**：营销事项台账、营销事项费用台账。

## 3. 页面布局重点
- **事项台账页**：采用“看板+列表”模式。顶部 3 个关键指标：`本月事项总额`、`待核销金额`、`异常预警数`。
- **申请表单页**：重点展示“营销活动明细”表格，支持在表单内直接添加多行活动场景。
- **费用明细抽屉**：从台账点击已用金额，弹出抽屉展示该事项下挂载的所有费用流水（报销、对公付款）。

## 4. 列表页字段与表格列建议
### 4.1 营销事项台账
- **主要表格列**：事项名称、状态、事项总额、已用金额、剩余金额、预算科目、使用部门、提醒日期。
- **进度展示**：已用金额/事项总额可使用迷你环形进度条或百分比显示。

## 5. 新增 / 编辑 / 详情展示方式
- **预警提醒**：对于超过“提醒日期”未关闭的事项，在台账行前展示红色感叹号及 Tooltip。
- **动态汇总**：在申请单明细中修改金额时，顶部的“事项总额”实时滚动更新。
- **费用追溯**：详情页中提供“查看来源单据”链接，模拟跳转至报销单或付款单详情。

## 6. 核心操作按钮与反馈
- **模拟费用使用**：演示专用按钮，点击后弹框选择费用类型并输入金额，即时更新台账已用金额。
- **发起关闭**：对于执行完毕的事项，行内出现“关闭事项”按钮，引导至关闭单。
- **保存草稿**：Toast 提示“已保存，您可以在台账的草稿页签找到它”。

## 7. 状态标签与状态流转展示
- **进行中 / 审批中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已关闭 / 已完结**：`bg-green-50 text-green-600 border-green-200`
- **待关闭 (预警)**：`bg-orange-50 text-orange-600 border-orange-200`
- **已驳回 / 已过期**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **预算占用标识**：申请提交后，展示“预算已锁定”标签及模拟的预算流水号。
- **核销来源展示**：在费用明细中标记来源：`[个人垫付]`、`[对公付款]`。

## 9. normal / loading / empty / error 状态补充
- **Empty**：台账无事项时，展示“您还没有创建任何营销事项，点击右上角开始”。
- **Error**：事项总额超过 5W 提交时，表单顶部展示红色 Alert 提示规则限制。

## 10. Codex 实现注意事项
- **金额回写模拟**：实现一个 `useMatterUpdate` hook，模拟外部业务对事项余额的扣减。
- **截止日期逻辑**：默认设置提醒日期为 `申请日 + 30天`，用于展示预警 UI。
