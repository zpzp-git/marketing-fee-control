# 3.7.10 营销合同管理 - UI/UX 补充说明

本说明旨在指导“营销合同管理”模块的 UI/UX 实现，重点在于如何展示复杂的合同结构、PO 执行明细以及直播计费规则，并确保财务复核流程的直观性。

## 1. 模块 UI 目标
- **信息分层展示**：将合同的基础信息、财务补充、履约进度进行有效隔离。
- **财务复核直观化**：对比展示“系统同步信息”与“财务补充信息”。
- **履约监控可视化**：直观展示合同金额与已执行 PO 金额的占用关系。

## 2. 页面清单
- **台账类**：营销合同台账、直播业务计费规则台账。
- **表单类**：合同结构化信息复核、合同 PO 执行单、达人 PO 执行单、直播任务确认单、直播坑位费结算单。
- **详情类**：营销合同详情（全景页）。

## 3. 页面布局重点
- **合同台账**：顶部增加摘要卡片展示：`合同总数`、`待复核数`、`履约中金额`、`同步失败数`。表格支持横向滚动。
- **结构化复核页**：左侧/顶部展示只读的“合同系统原件信息”，右侧/下方展示“财务补充信息”表单。
- **合同详情页**：采用页内 Tab 结构：`基础信息` | `合同明细` | `履约/PO` | `发票/摊销` | `审批日志`。

## 4. 列表页字段与表格列建议
### 4.1 营销合同台账
- **主要表格列**：合同编号、合同标题、供应商、签约主体、合同金额、复核状态、合同状态、同步状态、操作。
- **金额对齐**：所有金额列（合同金额、PO 金额等）强制右对齐。

### 4.2 直播业务计费规则台账
- **主要表格列**：规则编号、达人昵称、合同编号、结算方式、佣金比例、坑位费、状态。

## 5. 新增 / 编辑 / 详情展示方式
- **全景详情**：合同详情页的“履约/PO”页签中，使用嵌套表格或汇总卡片展示：`合同总金额` vs `已下单 PO 合计` vs `余额`。
- **复核表单**：对“是否广宣”、“是否摊销”等关键开关项，使用 Switch 组件并联动显隐下方日期/金额字段。
- **PO 关联选择**：在 PO 执行单中选择合同时，弹窗列表应突出展示合同的“可用余额”。

## 6. 核心操作按钮与反馈
- **结构化复核提交**：点击后弹出确认框，告知将生成的摊销/预估 mock 数据量。
- **模拟同步合同**：列表页右上角次按钮，点击后展示“同步中”状态条，500ms 后提示“成功同步 2 条新合同”。
- **发起终止/变更**：点击时立即执行“在途校验”，如失败则以 Modal 形式展示在途单据清单。

## 7. 状态标签与状态流转展示
- **待复核**：`bg-slate-100 text-slate-600`
- **复核中 / 变更中**：`bg-blue-50 text-blue-600 border-blue-200`
- **已生效 / 履约中**：`bg-green-50 text-green-600 border-green-200`
- **已终止**：`bg-gray-200 text-gray-500`
- **同步失败**：`bg-red-50 text-red-600 border-red-200`（带 Tooltip 说明原因）。

## 8. 第三方系统 mock 展示方式
- **合同原件预览**：提供“查看原件”按钮，点击弹出抽屉，展示 mock 的 PDF 文档信息流（无需真实 PDF）。
- **外部单号链接**：合同编号展示为蓝色链接，点击弹出 Toast：“已模拟跳转至合同系统详情”。
- **金额回写模拟**：PO 审批通过后，合同详情页的“已结算金额”数字应有动态增加的动画效果（模拟数据更新）。

## 9. normal / loading / empty / error 状态补充
- **Loading**：大型合同数据加载使用局部 Spinner。
- **Error**：在复核页，如果摊销日期不合法，在日期选择器下方展示红色错误文案。
- **Empty**：台账无数据时展示“暂无归档合同，请尝试模拟同步”。

## 10. Codex 实现注意事项
- **计算逻辑**：前端实现含税/不含税/税额的实时联动计算公式。
- **数据串联**：确保 PO 执行单选中的合同，其 ID 与合同台账中的记录一致，以展示联动更新。
- **横向滚动**：表格列较多时（>8列），固定左侧“合同编号”和右侧“操作”列。
