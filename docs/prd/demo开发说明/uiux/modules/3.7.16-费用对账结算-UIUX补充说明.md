# 3.7.16 费用对账结算 - UI/UX 补充说明

本说明旨在指导“费用对账结算”模块的 UI/UX 实现，确保其符合全局设计规范，并突出“多源对账 -> 自动核销 -> 异常处理”的专业闭环。

## 1. 模块 UI 目标
- **对账结果明确化**：一眼识别对账一致、有差异、待确认的记录。
- **异常处理引导化**：对于存在差异的记录，强制引导填写差异原因。
- **核销链路透明化**：清晰展示从预估费用到预提，再到最终对账结算的回写关系。

## 2. 页面清单
- **工作台**：费用对账结算工作台（仪表盘）。
- **表单类**：投放自动对账单、供应商对账单、资金账单结算单、费用预提单、费用摊销单。
- **台账类**：费用预提台账。

## 3. 页面布局重点
- **投放对账单**：采用“左右/上下对比”布局。左侧显示“平台消耗”，右侧显示“系统预估”，中间高亮差异值。
- **资金账单结算单**：明细表使用高密度模式，通过图标标识命中的“解析规则”。
- **费用摊销单**：展示本月应摊销的合同清单，带有一键计算功能。

## 4. 列表页字段与表格列建议
### 4.1 投放自动对账单明细
- **主要表格列**：费用日期、现金消耗、预估费用、差异金额、差异原因、对账结果、操作。
- **颜色提示**：差异金额不为 0 时，数字使用红色。

### 4.2 费用预提台账
- **主要表格列**：单据编号、预提月份、供应商、预算科目、预提金额、是否对账、是否冲销、操作。

## 5. 新增 / 编辑 / 详情展示方式
- **自动对账过程**：点击“执行自动对账”时，展示类似扫描的动画效果，逐行打上“一致”或“差异”标记。
- **差异录入**：差异原因为下拉选择 + 文本补充，支持批量应用相同原因。
- **预提汇总**：在预提单中，将相同科目的预估记录自动归集显示，提高扫描性。

## 6. 核心操作按钮与反馈
- **模拟导入账单**：表单顶部动作，点击后展现“数据同步 -> 智能匹配 -> 计算差异”的步骤条。
- **审批回写**：审批通过后，展示受影响的“来源台账”清单。
- **生成待到票**：结算完成后，底部出现“已自动生成待到票记录”的通知横幅。

## 7. 状态标签与状态流转展示
- **未处理 / 未对账**：`bg-slate-100 text-slate-600`
- **对账中 / 审批中**：`bg-blue-50 text-blue-600 border-blue-200`
- **一致 / 已对账 / 已完成**：`bg-green-50 text-green-600 border-green-200`
- **有差异 / 对账失败**：`bg-red-50 text-red-600 border-red-200`

## 8. 第三方系统 mock 展示方式
- **OMS/RPA 标记**：明细行展示 `[RPA]` 或 `[OMS]` 标签，标识数据来源。
- **凭证一键跳转**：凭证号点击后，侧边弹出凭证详情（Mock）。
- **计算逻辑悬浮**：鼠标悬停在“差异金额”上，展示：`现金消耗 - 预估费用 = 差异`。

## 9. normal / loading / empty / error 状态补充
- **Empty**：对账单内无匹配记录时，展示“来源数据已变更或已完成对账”。
- **Loading**：大型供应商对账时，使用表格局部 Shimmer 加载。

## 10. Codex 实现注意事项
- **自动对账函数**：实现基于 `账号+日期` 的明细匹配逻辑。
- **差异实时更新**：在表格内直接编辑“结算金额”时，自动更新“差异金额”和“对账结果”。
- **关联回写**：模拟审批后，更新对应费用预估台账的对账标识。
