# 3.7.16 费用对账结算模块实现说明

本文用于指导 Gemini 和 Codex 实现“费用对账结算”模块 Demo。不要按正式 PRD 重写，优先做出能演示、能闭环、能跑通的前端 mock 页面。

## 模块目标

费用对账结算模块用于承接费用预估、平台资金账单、合同摊销结果和供应商结算数据，完成对账、预提、摊销、入账和待到票生成的 Demo 闭环：

- 支持投放账单自动对账，展示现金消耗、业务消耗、对账结果、差异金额和差异原因。
- 支持供应商对账结算，按供应商、合同、期间汇总结算金额和预估费用差异。
- 支持资金账单结算，将平台扣款类资金账单模拟入账，并按有票/无票规则生成待到票或无票核销状态。
- 支持费用预提单从单次执行、佣金/直播等费用预估记录生成预提，并回写费用预提台账。
- 支持费用摊销单按合同摊销台账生成本月摊销金额，并回写合同摊销费用台账和预算发生数。
- 支持费用预提台账查询、详情、导出模拟和对账/冲销状态展示。

Demo 阶段重点跑通“来源数据 -> 对账/预提/摊销/入账单据 -> 审批通过 -> 台账状态回写”的闭环，不接真实 RPA、影刀、OMS、合同系统、ERP、金蝶、发票系统或银行系统。

## Demo 业务闭环

优先实现 5 条可演示闭环：

1. 投放自动对账闭环：从投放费用预估台账选择未对账记录 -> 模拟导入现金消耗数据 -> 按充值账户、费用日期、投放账户匹配业务消耗 -> 自动计算差异金额 -> 确认对账结果和差异原因 -> 审批通过后回写投放费用预估台账的是否对账、对账日期、对账结果、差异金额和差异原因。
2. 供应商对账闭环：选择供应商、合同和对账期间 -> 自动带出单次执行/费用预提记录 -> 汇总结算金额合计和差异金额合计 -> 审批通过后回写费用预提台账是否对账、是否冲销、对账单号，并回写单次执行费用预估台账的对账金额和对账结果。
3. 资金账单结算闭环：模拟 OMS 推送资金账单 -> 展示费用日期、支出金额、入账金额、OMS 大类/业务小类、预算科目、费用类型、收款账号 -> 审批通过后更新平台扣款费用台账为已入账，并按有票/无票规则生成待到票 mock 记录。
4. 费用预提闭环：选择未预提的单次执行费用预估、佣金/直播费用预估记录 -> 生成预提汇总和费用预估明细 -> 审批通过后插入费用预提台账，并回写来源预估台账是否预提、预提金额。
5. 费用摊销闭环：选择合同摊销费用台账中摊销中的合同 -> 按摊销月份计算本月摊销天数和本月摊销金额 -> 审批通过后增加合同摊销费用台账费用入账金额，并更新预算台账实际发生数。

可选演示闭环：

- 差异处理：对账差异不为 0 时必须填写差异原因，状态展示为“差异待确认”或“有差异”。
- 审批驳回：审批中单据被驳回后回到可编辑状态，不回写台账。
- 同步失败：OMS/RPA 同步失败时展示失败原因，允许重新同步并更新前端状态。
- 待到票联动：供应商对账单、资金账单结算单审批通过后，在发票管理的待到票 mock 数据中可看到对应记录。

跨模块数据只做 mock 串联：

- 投放费用预估台账、单次执行费用预估台账、佣金/直播费用预估台账、平台扣款费用台账、合同摊销费用台账来自费用预估模块 mock。
- 合同、供应商、预算科目、费用类型、店铺、品牌、渠道、三方账户来自基础数据、营销合同和预算管理 mock。
- 待到票台账、无票核销申请单号、凭证号、预算发生数只做本地状态模拟。

## 主要字段建议

通用单据主表字段：

- 单据编号、申请日期、申请人、申请人公司、申请人部门、申请人岗位、核算主体、单据状态、审批状态、凭证号、说明。
- 审批区：流程环节名称、审批人、审批日期、审批意见。
- 操作日志：操作人、操作时间、操作类型、操作结果、失败原因。

投放自动对账单：

- 主表：核算主体、供应商、合同编号、对账日期、差异金额、说明。
- 现金消耗明细：充值账户、费用日期、现金消耗金额、预估现金消耗、差异金额、差异原因、对账结果、业务对接人、财务对接人、店铺、营销活动。
- 业务消耗明细：投放账户、充值账户、费用日期、账户消耗金额、扣款金额、差异金额、营销活动计划分类、营销活动、预算科目、预算部门、费用类型、店铺、品牌、渠道。
- 关键规则：差异金额=现金消耗金额-预估现金消耗，或结算口径下的实际金额-预估金额；有差异时必须填写差异原因。

供应商对账单：

- 主表：核算主体、供应商、合同编号、对账日期、结算金额合计、差异金额合计、是否有预提、凭证号、说明。
- 供应商结算明细：开始日期、结束日期、预估费用、结算金额、差异金额、差异原因、对账结果。
- 费用预提明细：预提单号、关联 PO 执行单、费用日期、预估费用、差异金额、营销计划、营销活动计划分类、营销活动、预算科目、预算部门、费用类型、店铺、品牌、渠道。
- 关键规则：差异金额=结算金额-预估费用；审批通过后对账金额=预估费用+差异金额。

资金账单结算单：

- 主表：核算主体、供应商、数据来源、合同编号、入账日期、凭证号、说明。
- 资金账单项明细：费用日期、支出金额、入账金额、OMS 大类、OMS 业务小类、营销活动计划分类、营销活动、预算科目、预算部门、费用类型、店铺、品牌、渠道、收款账号、关联主键。
- 预算区：预算部门、预算科目、金额。
- 关键规则：审批通过后平台扣款费用台账是否入账=是，入账单据号=单据编号，预提金额=入账金额。

费用预提单：

- 主表：核算主体、预提金额合计、凭证号。
- 预提汇总：预提月份、预提金额、供应商、预算科目、预算部门、费用小类、店铺、品牌、渠道、核算科目。
- 费用预估明细：预估台账、费用日期、预估费用、预提金额、供应商、营销活动、预算科目、预算部门、费用类型、店铺、品牌、渠道、关联主键。
- 关键规则：审批通过后插入费用预提台账；预提月份取费用日期年月；预算台账发生数增加预提金额。

费用摊销单：

- 主表：核算主体、本月摊销金额合计、凭证号。
- 摊销汇总：摊销月份、日摊销额、本月摊销金额、预算科目、预算部门、品牌、核算科目。
- 合同摊销费用明细：合同编号、供应商、摊销开始日期、摊销结束日期、日摊销额、本月摊销天数、本月摊销金额、预算科目、预算部门、费用类型、核算科目、品牌。
- 关键规则：本月摊销金额=日摊销额*本月摊销天数；审批通过后合同摊销费用台账费用入账金额增加本月摊销金额。

费用预提台账：

- 查询字段：单据编号、核算公司、预提月份、供应商、预算科目、是否对账、是否冲销。
- 列表字段：单据编号、预提月份、预提金额、核算主体、供应商、预算科目、预算部门、店铺、品牌、渠道、核算科目、是否对账、是否冲销、对账单号。

状态枚举：

- 单据状态：草稿、审批中、已审批、已驳回、已作废。
- 对账结果：一致、有差异、待确认。
- 对账状态：未对账、对账中、已对账、差异待处理。
- 预提状态：未预提、审批中、已预提、预提失败。
- 摊销状态：未摊销、摊销中、已摊销、摊销失败。
- 入账状态：未入账、入账中、已入账、入账失败。
- 发票状态：发票未到、已无票核销、已到票。
- 同步状态：未同步、同步中、同步成功、同步失败。

## 关键交互

- 工作台顶部展示摘要指标：本月结算金额、差异金额、待对账、待预提、待摊销、待入账、同步失败。
- 各单据列表支持按单据编号、核算主体、供应商、合同编号、期间、状态、是否对账、是否冲销筛选。
- 单据详情按“主表信息 + 汇总区 + 明细区 + 审批信息 + 操作日志”组织。
- “生成投放自动对账单”打开抽屉，选择期间、供应商、投放账户或充值账户，从 mock 投放费用预估台账生成现金消耗和业务消耗明细。
- “生成供应商对账单”选择供应商、合同、开始日期、结束日期，自动带出费用预提明细和单次执行预估记录。
- “模拟同步 OMS 资金账单”展示同步批次、成功条数、失败条数、失败原因；成功后插入资金账单项明细。
- “生成费用预提单”支持批量选择未预提记录，同一条来源记录不可重复选择。
- “生成费用摊销单”按摊销月份批量选择合同摊销记录，自动计算本月摊销天数和金额。
- 提交审批后状态从草稿变为审批中；审批通过后生成凭证号或对账单号并回写台账；审批驳回后允许编辑重提。
- 差异金额不为 0 时，对账结果自动置为有差异，并要求填写差异原因。
- 导出、同步、生成凭证、生成待到票、推送审批全部只做前端反馈和状态更新。

## 第三方系统处理方式

- RPA/影刀、OMS、合同系统、营销计划系统、ERP、金蝶、发票系统、银行系统全部 mock。
- 保留外部动作按钮，但只更新前端状态和操作日志：
  - “模拟导入 RPA 账单”：生成投放现金消耗 mock 明细。
  - “模拟标准账单转换”：切换成功/失败；失败时展示投放计划名称、账户、预算科目等问题。
  - “模拟同步 OMS”：生成资金账单结算明细或同步失败原因。
  - “模拟生成凭证”：生成 `PZ-YYYYMM-####` 凭证号并回写单据。
  - “模拟生成待到票”：生成待到票记录，不调用真实发票系统。
  - “模拟推送审批”：新增审批记录并切换审批状态。
  - “模拟导出”：toast 提示已生成导出任务，不创建真实文件。
- 不连接真实外部接口，不使用真实账号、密钥、账单文件、发票文件或银行付款能力。

## UI/UX 重点

- 整体按财务 B 端后台设计，突出核算主体、供应商、合同、期间、预估金额、结算金额、差异金额、对账/预提/摊销/入账状态。
- 工作台使用摘要指标 + 待处理列表 + 差异列表 + 同步异常列表，方便演示人员快速进入闭环。
- 表格首屏固定关键列：单据编号、供应商、合同编号/账户、期间、金额、差异、状态、操作。
- 金额统一右对齐、千分位展示；预估金额、结算金额、差异金额用同一视觉规则便于比较。
- 状态标签明确：未处理为默认，审批中/同步中为处理中，已审批/已对账/已预提/已入账为成功，有差异/驳回/失败为警示或失败。
- 字段较多的明细区使用分组、横向表格、抽屉详情或列配置，不把所有字段挤在首屏。
- 差异原因、同步失败原因、规则命中结果要在行内或详情抽屉中直接可见。
- 空状态提供“生成对账单”“模拟同步 OMS”“重置筛选”；错误状态提供“重新同步”“重新匹配”“查看失败原因”。
- 不做真实附件上传；附件区只展示 mock 附件名称和预览占位。

## 验收标准
