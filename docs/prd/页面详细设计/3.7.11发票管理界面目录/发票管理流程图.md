

# 发票管理流程图

## 1.发票核销流程

### Mermaid 流程图

```mermaid
flowchart TD
    subgraph 业务
        Start((开始)) --> N1[1.0 点击发票核销单，并创建单据<br>业财中台]
        N1 --> N2[2.0 批量上传发票并做系统校验<br>业财中台]
        N2 --> N3[3.0 关联结算信息<br>业财中台]
    end
    
    subgraph 财务
        N3 --> N4[4.0 接收代办消息<br>OA]
        N4 -- 接收线下发票 --> N5[5.0 签收纸质发票<br>业财中台]
        N5 --> Cond1{审核是否通过}
        Cond1 -- "N (状态变为未提交)" --> N2
        Cond1 -- Y --> N6[6.0 生成凭证<br>业务中台]
        N6 --> N7[7.0 生成总账凭证<br>金蝶]
        N7 --> N8[8.0 单据上记录金蝶凭证号<br>业财中台]
        N8 --> End((结束))
    end
```
